## 🔄 גיליונות השיקוף של הטיסות בקובץ הראשי (Master Mirror Sheets)

בקובץ הראשי קיימים **שני גיליונות שיקוף שונים ונפרדים** המשקפים מידע מקובץ הטיסות של ענת:

### א. גיליון: `טיסות - שיקוף`
* **מקור המידע:** שיקוף ישיר של הגיליון **`עדכוני טיסות`** מהקובץ של ענת.
* **מטרה ותפקיד במערכת:** 
  * מציג עדכונים שוטפים של תהליך תיאום והזמנת הטיסות.
  * מרכז את המידע הנדרש עבור ענת להזמנת הכרטיסים (העדפות אוכל, מושבים, אישורי הצעות, מחירי כרטיסים, דמי ביטול וכו').
  * **אינטגרציה עם דשבורד הפקה:** דשבורד ההפקה שולף מגיליון זה נתונים קריטיים על סטטוס האורחים (מי מחכה לכרטיס, מה חסר ומה מצב האישור של כל אחד).
* **מבנה עמודות:** זהה לחלוטין לגיליון `עדכוני טיסות` (עמודות A עד AE).

### ב. גיליון: `טבלת טיסות - שיקוף`
* **מקור המידע:** שיקוף ישיר של הגיליון **`טבלת טיסות`** מהקובץ של ענת.
* **מטרה ותפקיד במערכת:** 
  * מציג תמונת מצב נקייה וממוקדת של הטיסות בפועל, ללא עומס של תהליך ההזמנה, הצעות מחיר ועלויות.
  * משמש בעיקר לטובת **חיבור ותיאום אורחים לשאטלים / הסעות**, וקבלת סיכום ברור ופשוט של מועדי הגעתם ויציאתם מהארץ.
* **מבנה עמודות (A עד M):**

| :---: | :--- | :--- |

| **B** | `שם משפחה` | שם משפחה של האורח |
| **C** | `שם פרטי` | שם פרטי של האורח |

| **F** | `מספר טיסה נחיתה` | מספר טיסת הגעה |
| **G** | `חברת תעופה נחיתה` | חברת תעופה טיסת הגעה |

### 3. גיליון: `הסעות מנתבג`
לוח ניהול הסעות ושאטלים מנתב"ג, הניזון אוטומטית מתוך `טבלת טיסות`.

* **נוסחת השליפה הראשית:**
  ```excel
  =QUERY('טבלת טיסות'!A:N, "SELECT C, B, D, E, F, G, L WHERE D IS NOT NULL ORDER BY D ASC, E ASC", 1)
  ```
* **מבנה העמודות המוצגות (לפי ה-SELECT):**
  1. **C** – `שם פרטי`
  2. **B** – `שם משפחה`
  3. **D** – `תאריך נחיתה`
  4. **E** – `שעת נחיתה`
  5. **F** – `מספר טיסה נחיתה`
  6. **G** – `חברת תעופה נחיתה`
  7. **L** – `שיוך לשאטל`
* **לוגיקת סינון ומיון:** מסנן רק אורחים עם תאריך נחיתה קיים (`WHERE D IS NOT NULL`) וממיין כרונולוגית לפי תאריך ושעת נחיתה (`ORDER BY D ASC, E ASC`).

## 🔒 גיליון `Auth_Sessions` (מערכת ההתחברות)

מוסתר אוטומטית. נוצר ע"י ה-Backend אם אינו קיים. מנהל את הסשנים הפעילים.
**הערת ארכיטקטורה:** אין לשקף/להעתיק נתונים מגיליון זה בין סביבת Production לסביבת Sandbox כדי לשמור על הפרדת אבטחה. כל סביבה מייצרת טוקנים עצמאיים.

| עמודה | שם עמודה | משמעות |
| :---: | :--- | :--- |
| **A** | `Email` | מייל האורח |
| **B** | `SessionToken` | אסימון ההתחברות (מחרוזת UUID) |
| **C** | `LastActiveMs` | זמן פעילות אחרון (במילישניות) המשמש לניתוק אוטומטי (Session Expiration) |
| **D** | `CreatedAt` | תאריך ושעת ההתחברות המקורית |
